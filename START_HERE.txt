EDXSO SCHOOL INFLUENCER DISCOVERY MVP

1) Extract the ZIP.
2) Open PowerShell in the extracted folder.
3) Run:
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   streamlit run app.py
4) Open http://localhost:8501

Read README.md for GitHub/deployment instructions.
The app uses a 25-record sourced public-source test corpus. It does not scrape LinkedIn.
